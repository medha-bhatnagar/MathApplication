# Math Practice

A child-friendly math practice app built with React, TypeScript, and Vite. It supports configurable arithmetic practice, session summaries, local statistics, settings, and personalized mistake review.

Practice history is kept in this browser using local storage. No account or network connection is needed after the app loads.

## Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm run format:check
npm test
npm run build
```
